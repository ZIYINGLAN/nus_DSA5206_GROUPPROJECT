## Methodology and interpretation

- OLS, Pearson correlation, R², MAE and MSE are unchanged. Tolerance accuracy now uses absolute error strictly below 0.7; equality fails. There are 50 patient-grouped splits per target/feature combination.
- The no-data baseline is an intercept-only predictor (`0+1`). Pearson correlation with a constant predictor is undefined and displayed as N/A. The paper's approximate-zero entry is not the mathematical value; it is not substituted into results.
- Figure 3 uses the author's four pre-sigmoid outputs: Lung Opacity, Pneumonia, Infiltration, Consolidation. No feature standardization is introduced. One 208-image embedding is reused for both seed-0 and seed-49 regression comparisons. t-SNE uses seed 54, perplexity 30, learning rate 200, random initialization, two dimensions; pinned scikit-learn defaults provide Euclidean distance, Barnes–Hut and 1000 iterations. Filename manifests document row order. The author notebook's saved `(199,2)` embedding conflicts with the paper's 208-image description. No historical manifest/revision explains the nine-image difference; its cause remains unresolved. No images are removed to match 199.
- Figure 4 preserves seed-0 illustrative case-selection rules, deliberately selecting close predictions and extreme errors using test outcomes. These examples are not a representative sample. A follows released code: squared gradient, sigma 5, truncate 3.5, nearest boundary, effective 37×37 support. B interprets the paper's 5×5 description using signed gradients, a normalized discrete sigma-1 kernel and reflect boundaries. These unspecified choices make B an interpretation, not an exact reconstruction. Inputs, checkpoint and regression are shared; each method has a global scale across cases, but separate colorbars because gradient and squared-gradient units differ.
